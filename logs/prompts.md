# 关键提示词记录（prompts.md）

本文件记录开发过程中使用的关键 AI 提示词，便于评审了解 AI Coding 的实际用法。

## 一、角色与约束类

```
你是我的 VelaTime 项目开发搭档。约束：
1. 一次只给一小步操作，我执行并回报结果后你再给下一步；
2. 命令必须说明在哪个终端/提示符下执行，并写清期望输出；
3. 不允许猜测文件内容，改代码前先读取真实文件；
4. 遇到报错先定位根因，不要连续试错。
```

## 二、需求与设计类

```
VelaTime 是面向高校学生的主动式时间管家。
需求：Agent 负责理解与规划，设备负责触达与执行。
请设计"任务/课程/空闲窗口/推荐"四个核心模块的数据结构与接口，
要求：纯 C、可在 NuttX 上编译（-Werror）、不依赖动态内存分配。
```

```
请把"截止日期紧迫度"设计成分层评分（逾期/今天/明天/3天内/一周内/更远），
并给出可解释的推荐理由文案格式，便于直接显示在手表屏幕上。
```

## 三、排错类（节选真实提问）

```
链接报错：libgui_wrapper.a: file format not recognized。
请判断根因（不要直接让我重装工具链），并给出验证方法。
```

```
模拟器黑屏但串口日志显示内核和 adbd 都正常，请给出排查顺序。
```

```
Agent 回复 401 Invalid API Key，但我在 Windows 上用同一个 Key 请求是 200。
请设计一个能区分"Key 无效 / 端点不对 / 代理未生效 / 参数被截断"的验证方案。
```

```
- [ ] [2026-09-08] 这样的日期格式能否被我的解析器接受？
请检查我的 sscanf 格式串与 Agent 实际写入格式是否一致。
```

```
界面卡片文字溢出并出现横向滚动条，请给出 LVGL 9 的布局修复方案，
要求不使用绝对坐标堆叠。
```

## 四、字库类

```
内置 lv_font_simsun_16_cjk 缺少"业"字，font_multilang_small 汉字太少。
请在虚拟机里确认字符覆盖情况，并给出生成自定义中文字库的完整方案
（含字符集来源、生成命令、字体回退与固件体积评估）。
```

## 五、验证类

```
请把工程里真实的 core_agent_sync.c 与 core_task.c 编到宿主机上做单元测试，
用 -D 把数据文件路径改到 /tmp，覆盖以下场景：
未变化不触发、变化需连续两次稳定才应用、文件消失不破坏内存数据、
标记完成触发同步。
```

```
请为主动提醒写单元测试：publish 写出 HEARTBEAT.md、
REMINDER.txt 不存在/内容重复/模板占位符/空内容/无待办 等边界都要覆盖。
```

## 六、协作方式说明

- 前期（opencode 会话）：以"人执行、AI 给命令"为主，
  每条命令都要求回报输出，AI 据此判断下一步；
- 后期（DeepSeek Harness）：AI 通过 SSH 直连开发虚拟机，
  自己上传文件、触发编译、轮询日志、跑单元测试，人只做界面确认与决策；
- 两种方式都遵循同一原则：**先读真实代码与真实日志，再改，再验证。**
